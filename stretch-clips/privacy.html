퍼스널클립 개인정보처리방침

시행일: 2026년 11월 10일 · 운영자: Seolin Yang (개인 개발자)

요약: 퍼스널클립은 회원가입이 없고, 운영자 서버도 없어요. 기본 설정에서는 영상, 음성, 받아 적은 텍스트가 모두 기기 안에서만 처리되고 밖으로 나가지 않아요. 이용자가 설정에서 ‘Claude로 나누기’를 켜고 본인의 API 키를 넣은 경우에만 받아 적은 텍스트를 Anthropic(미국)에 보내요.

1. 처리하는 정보와 목적

사진 보관함의 수업 영상이용자가 고른 영상을 불러와 동작별 클립으로 자르는 데 쓰여요. 원본은 바꾸지 않고, 잘라 낸 클립은 앱 저장 공간에 저장돼요.
영상 속 음성강사의 설명을 텍스트로 받아 적는 데 쓰여요. Apple 음성 인식으로 기기 안에서 처리하고, 음성 자체는 전송하지 않아요.
받아 적은 텍스트동작이 시작하고 끝나는 지점을 찾는 데 쓰여요. 기본 설정에서는 앱에 들어 있는 모델이 기기 안에서 처리해요. ‘Claude로 나누기’를 켠 경우에만 Anthropic으로 보내요(아래 3항).
학습 자료이용자가 구간을 고쳐 저장하면, 받아 적은 텍스트와 고친 구간(시작·끝 시각)을 기기 안에 저장해요. 구간 나누기를 더 정확하게 만드는 데 쓰려는 자료예요. 이용자가 설정에서 직접 ‘내보내기’를 누르기 전에는 기기 밖으로 나가지 않아요.
Anthropic API 키 (선택)‘Claude로 나누기’를 쓸 때만 이용자가 직접 입력하는 키예요. 기기의 키체인에 이 기기 전용으로 저장되고, Anthropic에 요청할 때만 쓰여요. 운영자에게 전송되지 않아요.
루틴·부위 태그·설정이용자가 만든 루틴, 몸 부위 태그, 앱 설정. 기기에만 저장돼요.

이름, 이메일, 전화번호, 위치, 광고 식별자는 수집하지 않아요. 광고, 분석 도구, 추적 기능도 없어요.

음성 인식과 문장 분석에 필요한 언어 자료가 기기에 없으면, iOS가 Apple에서 내려받을 수 있어요. 이때 받아 적은 텍스트나 영상은 보내지 않아요.

2. 보관 기간과 파기

  • 클립, 받아 적은 텍스트, 학습 자료, 루틴은 기기 안의 앱 저장 공간에만 있어요. 수업을 지우면 해당 클립과 정보, 학습 자료가 함께 지워지고, 앱을 삭제하면 모두 지워져요.
  • 학습 자료는 설정의 ‘모두 지우기’로 언제든 지울 수 있어요.
  • API 키는 설정 화면에서 지울 수 있어요.
  • 사진 보관함의 원본 영상은 앱이 지우거나 바꾸지 않아요.

3. 국외로 전송되는 정보 (‘Claude로 나누기’를 켠 경우에만)

기본 설정에서는 국외로 전송되는 정보가 없어요. 아래 내용은 이용자가 설정에서 ‘Claude로 나누기’를 켜고 본인의 API 키를 넣은 경우에만 해당돼요.

받는 곳Anthropic, PBC (미국) · api.anthropic.com
보내는 항목영상에서 받아 적은 텍스트와 각 줄의 시각, 영상 길이, 몸 부위 목록
목적텍스트를 분석해 동작별 구간을 나누기 위해서예요.
시점과 방법‘Claude로 나누기’가 켜진 상태에서 영상 처리를 시작할 때, 암호화된 연결(HTTPS)로 보내요.
보관 기간이용자 본인의 API 키로 요청하므로, Anthropic이 받은 데이터는 이용자와 Anthropic 사이의 약관과 Anthropic 개인정보처리방침에 따라 다뤄져요. 운영자는 이 데이터를 받거나 볼 수 없어요.
거부 방법‘Claude로 나누기’를 끄거나 API 키를 지우면 아무것도 전송되지 않아요. 이때도 구간 나누기는 기기 안에서 계속 쓸 수 있어요.

영상 속 강사의 설명에는 강사나 다른 사람의 이름 같은 정보가 들어 있을 수 있어요. 다른 사람이 나오는 수업 영상은 그 사람의 동의 범위 안에서 사용해 주세요.

학습 자료를 ‘내보내기’로 꺼내면, 이용자가 고른 곳(예: AirDrop, 파일 앱)으로만 전달돼요. 운영자에게 자동으로 보내지지 않아요.

이 밖에 다른 회사에 정보를 제공하거나 처리를 맡기지 않아요.

4. 접근 권한

  • 사진 (필수, 전체 접근): 수업 영상을 불러오고, 원본에서 클립을 잘라 내는 데 필요해요.
  • 음성 인식 (필수): 영상 속 설명을 기기 안에서 받아 적는 데 필요해요.

권한은 기기 설정에서 언제든 바꿀 수 있어요. 앱에 들어 있는 ‘예시 수업’은 권한 없이도 써 볼 수 있어요.

5. 이용자의 권리

정보가 모두 기기 안에 있어서, 이용자가 앱에서 직접 확인하고 지울 수 있어요. ‘Claude로 나누기’로 Anthropic에 보낸 데이터에 관해서는 Anthropic에 직접 요청할 수 있어요. 궁금한 점은 아래 연락처로 문의해 주세요.

6. 안전성 확보 조치

영상과 음성은 기기 밖으로 보내지 않고, API 키는 기기 키체인에 이 기기 전용으로 저장해요. 외부 전송은 암호화된 연결(HTTPS)로만 해요.

7. 만 14세 미만 아동

퍼스널클립은 아동을 대상으로 하지 않으며, 아동의 정보를 따로 수집하지 않아요.
