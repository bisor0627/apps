자주 묻는 질문

API 키가 필요한가요?
아니요. 구간 나누기는 기본적으로 기기 안에서 해요. 설정에서 ‘Claude로 나누기’를 켜고 본인의 Anthropic API 키를 넣으면 Anthropic의 AI로 나눌 수도 있어요. 이때 사용량에 따른 요금은 본인 Anthropic 계정에 청구돼요.

자동으로 나눈 구간이 틀려요.
구간 고치기 화면에서 노란 손잡이를 끌거나 ±1초 버튼으로 맞추고, 나누기·합치기·지우기로 고칠 수 있어요. 고친 결과는 기기 안에 학습 자료로 쌓이고, 앞으로 구간 나누기를 더 정확하게 만드는 데 쓰여요.

영상이 외부로 올라가나요?
아니요. 영상과 음성은 기기 안에서만 처리해요. 기본 설정에서는 받아 적은 텍스트도 밖으로 나가지 않아요. ‘Claude로 나누기’를 켠 경우에만 받아 적은 텍스트를 Anthropic으로 보내요. 자세한 내용은 개인정보처리방침을 봐 주세요.

원본 영상이 바뀌나요?
아니요. 클립은 복사본으로 앱 안에 저장되고, 사진 보관함의 원본은 그대로예요.

먼저 써 보고 싶어요.
수업 탭이 비어 있을 때 ‘예시 수업 둘러보기’를 누르면, 사진 권한 없이 구간 고치기·루틴·재생을 써 볼 수 있어요.
